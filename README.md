# Cisco Data Science Essentials 

### *Cisco Networking Academy Certification*

## 📋 Overview

This repository contains the coursework, lab solutions, and projects for the **Cisco Networking Academy "Data Science Essentials with Python"** certification. It serves as a comprehensive collection of core data science workflows: data ingestion, cleaning, exploration, visualization, modeling, and reporting.

My approach throughout this program has been **learning-driven**, focused on breaking models to understand how they work and ensuring that the visual narrative is always backed by scientifically sound preprocessing.

---

## 🏗️ The Learning Journey (Module-by-Module)

The repository is organized chronologically to reflect the five stages of the certification path.

### 1. [Coding for Answers](https://www.google.com/search?q=./Coding%2520for%2520Answers)

**Foundational Analytical Workflows**

* Translating real-world questions into data problems using Python scripts and Jupyter notebooks.
* **Focus:** Logic-first coding, Pandas-based analysis, and derriving insights from diverse datasets.

### 2. [Data Cleaning & EDA](https://www.google.com/search?q=./Data%2520Cleaning)

**The Preprocessing Core**

* Transforming "messy" real-world data into structured, high-integrity assets ready for machine learning.
* **Key Skills:** Handling missing values, relational merging (`merge`), and complex string parsing for future-dated predictions.
* **Highlights:** Solar Eclipses, Volcanic Eruptions, and Whale Heart Rate analysis.

### 3. [Data Visualization](https://www.google.com/search?q=./Data%2520visualization)

**Communicating Complex Insights**

* Moving beyond default charts to create contextually anchored Matplotlib and Seaborn visualizations.
* **Key Skills:** Custom direct-labeling, opinion disparity mapping, and managing magnitude extremes with logarithmic scaling.
* **Highlights:** How Couples Meet, Car Dimensions Evolution, and Spicy Pepper Intensity.

### 4. [Data Modeling](https://www.google.com/search?q=./Data%2520modeling)

**Statistical Integrity & Predictive Logic**

* Preparing data for predictive analytics through advanced statistical cleaning and feature engineering.
* **Key Skills:** Multicollinearity management, quadratic and polynomial regression, and object-oriented analysis (Custom Python classes).
* **Highlights:** Lion Nose Color tracking, Blood Pressure cross-cultural modeling, and Stopping Distance physics.

### 5. [Storytelling](https://www.google.com/search?q=./Data%2520integrity)

**The Professional Showcase**

* Identifying hidden data artifacts and mitigating bias to ensure business insights are mathematically sound.
* **Key Skills:** Periodicity analysis (biological lifecycles), time-series normalization across centuries, and inverse correlation analysis.
* **Highlights:** Silent Spring biomagnification, Cicadas Are Coming periodicity, and Warm Waters Peru analysis.
