# 🛠 Module: Data Cleaning & Exploratory Data Analysis (EDA)

Welcome to the **Data Cleaning** core module of the Cisco Data Science Program. This folder serves as a showcase of my ability to transform "messy," real-world datasets into structured, high-integrity assets ready for advanced machine learning and business intelligence.

## 🎯 Strategic Objective

In data science, **80% of the work is data preparation.** My goal in this module was to master the art of data wrangling using the `pandas` ecosystem, focusing on three pillars:

1. **Integrity:** Handling missing values, outliers, and incorrect data types.
2. **Transformation:** Converting human-readable strings into computable numerical and temporal features.
3. **Insights:** Using cleaned data to solve specific business and scientific "Why" questions.

## 🛠 Technical Toolkit

### Data Manipulation

* **Pandas:** Mastered `.groupby()`, `.pivot_table()`, `.query()`, and `.merge()`.
* **Vectorization:** Utilizing `df.eval()` and vectorized operations for performance over large datasets.
* **Feature Engineering:** Creating derived metrics (e.g., Sentiment scores, oxygen-debt recovery deltas).

### Cleaning & Standardizing

* **String Processing:** Advanced usage of `.str.split()`, `.str.replace()`, and Regex for data standardization.
* **Temporal Analysis:** Converting ISO and non-standard strings into `datetime64` objects for delta calculations.
* **Data Integrity:** Implementing strategies for `NaN` handling and type casting (`astype`, `convert_dtypes`).

## 📖 How to Use This Manual

This folder is organized by project type. Each sub-folder contains:

* `*.ipynb`: The core Jupyter Notebook containing documented code and logic.
* `*.csv`: The raw dataset used for the analysis.
* `README.md`: A recruiter-focused summary of the business problem, technical workflow, and key insights.

### To Run Locally:

1. Clone the repository.
2. Ensure you have the dependencies installed: `pip install pandas matplotlib jupyter`.
3. Open any folder and launch the `.ipynb` file to view the analysis step-by-step.
